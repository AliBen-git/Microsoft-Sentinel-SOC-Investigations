# Microsoft Sentinel Lab Modules

The broader learning path shared for this project contained the following ten modules. This list records the scope of the lab documentation; it does not imply that every module has a retained screenshot, query, or outcome in this repository.

1. **Environment Setup & Onboarding** — Azure and Sentinel lab environment setup.
2. **Data Connectors & Log Ingestion** — connecting data sources and ingesting logs.
3. **KQL Fundamentals** — querying and examining security data with KQL.
4. **Analytics Rules & Detection Engineering** — creating detections from log data.
5. **Incident Management & Investigation** — reviewing and investigating incidents.
6. **Threat Hunting** — proactive searches for suspicious activity.
7. **Workbooks & Visualization** — visualizing security data and trends.
8. **SOAR: Playbooks & Automation** — automation and response workflows.
9. **Threat Intelligence Integration** — using threat intelligence in investigations.
10. **Real-World Case Study: APT Simulation – Operation CloudStrike** — a simulated APT case study described in the lab outline.
